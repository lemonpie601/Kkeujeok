# 끄적 친구 (Typing Buddy)

[Marinara Engine](https://github.com/Pasta-Devs/Marinara-Engine) 채팅 입력창의 커서를 따라다니는 작은 친구예요.
글을 쓰면 끄적이고, 지우면 도리도리하고, 보내면 슝 날아가요. 하트가 뿅뿅 튀거나 잉크가 뚝뚝 떨어지게 꾸밀 수도 있어요.

## 할 수 있는 것

- **친구 그림**: 만년필·깃펜·연필, 또는 직접 올린 그림(PNG·WebP·JPG, 150KB 이하 움직이는 GIF)
- **상황별 움직임**: 입력창 누를 때 · 쓸 때 · 지울 때 · 줄바꿈 · 보낼 때 · 붙여넣을 때마다 30가지가 넘는 움직임 중에서 골라요. 쉴 때 움직임도 따로 있어요.
- **상황별 그림(표정)**: 지울 때만 우는 얼굴처럼, 상황마다 다른 그림으로 바꿀 수 있어요.
- **효과**: 하트·반짝이·별·꽃·음표·잉크 방울·비눗방울 등에 내 이모지나 내 그림까지. 뿅뿅·뚝뚝·팡파레 같은 모양 11가지.
- **나타나기·사라지기**: 서서히(페이드) 또는 바로(툭).
- **그림함과 프리셋**: 그림을 여러 장 담아 두고 지금 모습을 프리셋으로 저장해요. 그림까지 담아 파일로 내보내고 가져올 수 있어요.
- **어디서 열어도 같게**: 그림함·프리셋·설정을 Marinara 서버(확장 저장소)에 저장해요. PC, 폰, Tailscale 주소 어디서 열어도 똑같이 보여요. 떠 있는 버튼 위치처럼 기기마다 다른 것만 그 브라우저에 남아요.

## 설치

필요한 것: Marinara Engine 2.5.0 이상, 외부 확장 허용(`ENABLE_EXTERNAL_EXTENSIONS=true`, 설정 → 고급 → Danger Zone에서 서드파티 확장 가져오기 허용).

1. 설정 → 애드온 → External Extensions에서 이 저장소 주소(`https://github.com/lemonpie601/Kkeujeok`)를 연결해요.
2. 목록에 생긴 **끄적 친구 (Typing Buddy)**의 전원 아이콘(**Review and run**)을 눌러 **Run Exact Code**로 승인하면 바로 켜져요.

## 쓰는 법

- 화면 왼쪽 아래 동그란 연필 버튼을 누르면 꾸미기 창이 열려요. 버튼은 끌어서 옮길 수 있어요.
- 버튼을 숨겼다면 **Alt + Shift + K**로 다시 열 수 있어요.
- 꾸미기 창 맨 위 미리보기에서 친구가 혼자 쓰고, 지우고, 보내면서 지금 설정을 보여줘요.

## 업데이트할 때 꼭 지켜 주세요

- 그림함·프리셋·설정은 **설치된 확장에 묶인 서버 저장소**에 들어 있어요. 확장을 **지우고 새로 설치하면 그림이 사라질 수 있어요.**
- 새 버전은 지우지 말고 같은 확장 위에 **업데이트**로 받아 주세요. 업데이트된 확장은 꺼진 상태로 저장되니, 다시 **Review and run → Run Exact Code**로 승인해 주세요.
- 혹시 몰라서 걱정되면 꾸미기 창 → 프리셋 → **파일로 내보내기**로 백업해 두세요. 그림도 같이 담겨요.

## 서버 저장 공간

Marinara는 확장 하나당 **1MB**를 줘요. 그림은 160px WebP로 줄여 담아서 한 장에 보통 5~12KB예요. 꾸미기 창 맨 아래에서 사용량을 볼 수 있고, 꽉 차면 빨간 글씨로 알려줘요.

## 권한

입력창 위치를 읽고 친구를 화면에 띄우려고 `full_page_access`를 써요. 인터넷에서 아무것도 받아오지 않고, 저장은 Marinara 서버의 확장 저장소와 이 브라우저에만 해요.
